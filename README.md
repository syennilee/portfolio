## How to edit
- **All text (EN + KR)** is in [`js/content.js`](js/content.js). Open it on GitHub → ✏️ pencil icon → edit → **Commit changes**. The site updates in about a minute.
  - `null` means "to fill in" (shows in grey on the site).
  - Contact links (LinkedIn, Instagram, résumé PDF) are at the top under `CONTACT`.
- **Images** go in the [`images/`](images/) folder. Then write the file path in `IMAGES` inside `js/content.js`, e.g. `"images/brand-bx-cover.jpg"`.
- Design lives in `css/style.css`, interactions in `js/main.js`.
